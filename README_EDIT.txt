OPEN WEBSITE
1. Extract the ZIP.
2. Open index.html in a browser.

EDIT IN ACODE / VS CODE
Search the text "EDIT-" inside index.html.
Main editable sections:
- EDIT-NAME
- EDIT-COLOR
- EDIT-HERO
- EDIT-PHOTO
- EDIT-ABOUT
- EDIT-EXPERIENCE
- EDIT-PROJECTS
- EDIT-CREDENTIALS
- EDIT-SKILLS
- EDIT-CONTACT

IMPORTANT
Keep the folder structure intact because index.html uses relative links
to assets/, projects/, certificates/, and CV_Mardiyanto.pdf.

PUBLIC WEBSITE
To make this portfolio accessible through a public link, upload the complete
folder to a static web host such as GitHub Pages, Netlify, or Vercel.
